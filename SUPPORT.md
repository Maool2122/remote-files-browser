# Getting help

This repository is about the **helper program** that the Chrome extension Remote Files Browser FTP uses for FTP, FTPS and SFTP.

| You want to | Go here |
| --- | --- |
| Learn what the helper does, how to install it, and what its limits are | [helper/README.md](helper/README.md), then [docs/README.md](docs/README.md) |
| Fix a problem with FTP, FTPS or SFTP (the helper program) | [helper/docs/TROUBLESHOOTING.md](helper/docs/TROUBLESHOOTING.md) |
| Ask a question, or say that you cannot connect to a server | A [question](https://github.com/Maool2122/remote-files-browser/issues/new?template=question.yml) |
| Report something in the helper that does not work | A [bug report](https://github.com/Maool2122/remote-files-browser/issues/new?template=bug_report.yml) |
| Suggest something new for the helper | A [feature request](https://github.com/Maool2122/remote-files-browser/issues/new?template=feature_request.yml) |
| Tell us how the helper ran on macOS, Linux, Windows 10 or Windows on ARM | A [platform report](https://github.com/Maool2122/remote-files-browser/issues/new?template=platform_report.yml) |
| Report a security problem | **In private:** [SECURITY.md](SECURITY.md). Never in a public issue |
| Check that a download is genuine | [docs/VERIFYING-DOWNLOADS.md](docs/VERIFYING-DOWNLOADS.md) |
| Help build it | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Get help with the **extension** itself (its screens, its settings, its privacy) | <https://rocuo.com/remote-files/support/>. The extension is closed source, so it has no issues here. Its privacy policy: <https://rocuo.com/remote-files/privacy-policy/> |

## Before you write

- **Never put a password, a user name, a private server address or a private file name into an issue.** Everything in an issue is public. Use made-up values.
- Say what you did, what you expected, what happened (the words of the message), and your setup: the version of the helper (`rocuo-files-helper version`), the operating system, the browser, and the kind of place (FTP, FTPS, SFTP).
- This is a free project made by a small team. We read what you send, but we cannot promise a time for an answer, and we cannot look into the settings of your own server. A clear report, with the exact message, gets the fastest help.

The extension is published by Rocuo (<https://rocuo.com/remote-files/>). Its page in the [Chrome Web Store](https://chromewebstore.google.com/detail/remote-files-browser-ftp/pckgpblcplbjffapabndpkhnhkioihjd) is the place for reviews.
